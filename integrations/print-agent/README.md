# برنامج الطباعة الصامتة (Panorama Print Agent)

يعمل على اللابتوب المتصل بطابعة المحل. عندما يضغط موظف «تجهيز ملف الطباعة» في لوحة التحكم، يلتقط هذا البرنامج المهمة
ويطبعها **بلا أي نافذة** بالإعدادات الصحيحة (وجهان، لون، حجم ورق)، ثم يُبلغ اللوحة بالحالة (قيد الطباعة، تمت، فشلت).
الملف الذي يطبعه يحوي كل النسخ بالترتيب الصحيح وتوزيع الشرائح، لذلك يُطبع **مرة واحدة**.

الخيار اليدوي يبقى متاحًا دائمًا: زر «فتح للطباعة» في اللوحة يفتح الملف في نافذة طباعة المتصفح.

## المتطلبات
- Windows مع Python 3.10 أو أحدث (بلا مكتبات إضافية).
- [SumatraPDF](https://www.sumatrapdfreader.org/) مثبّت (الطباعة الصامتة).
- **حساب موظف مخصص للبرنامج** (دور «مسؤول طباعة»): لا تستعمل حسابك الشخصي لأن الدخول من مكان آخر يُنهي جلسة الحساب نفسه.
- عنوان الخادم يبدأ بـ `https://` (يرفض البرنامج غير ذلك، إلا لتجربة محلية بخيار `allow_insecure_http`).

## التثبيت
1. انسخ المجلد إلى اللابتوب، وانسخ `config.example.json` إلى `config.json` واملأه:
   - `api_base`: عنوان الخادم، مثل `https://api.xn--mgbaab0cxheq.tech`
   - `identifier` و`password`: حساب الطباعة المخصص.
   - `printer`: **اسم الطابعة كما يظهر في ويندوز** حرفيًا (الإعدادات ← الطابعات).
   - `sumatra_path`: مسار `SumatraPDF.exe` إن لم يكن الافتراضي.
2. جرّب مرة واحدة: `python print_agent.py --once` (يعالج الطابور الحالي ثم يخرج). السجل في `agent.log`.
3. للتشغيل الدائم عند فتح الجهاز: أنشئ مهمة في **Task Scheduler** (عند تسجيل الدخول) تشغّل
   `pythonw.exe C:\path\to\print_agent.py` وتعيد التشغيل عند الفشل.
4. اجعل `config.json` قابلًا للقراءة لحساب الويندوز الذي يشغّل البرنامج فقط (فيه كلمة المرور).

## كيف يعمل
| الخطوة | ما يحدث |
|---|---|
| 1 | يسجّل الدخول ويسأل كل 5 ثوانٍ عن المهام `queued` |
| 2 | يغيّر حالة المهمة إلى `printing` ويحمّل ملف PDF الجاهز |
| 3 | يتحقق أنه PDF حقيقي ثم يطبعه عبر SumatraPDF بإعدادات الطلب (`duplexlong` أو `duplexshort`، لون/أبيض وأسود، الورق) |
| 4 | يُبلغ `done` أو `failed` مع السبب؛ والفاشل يمكن إعادته من اللوحة |

إن كانت الطابعة لا تدعم الوجهين فسيطبع وجهًا واحدًا: اضبط ذلك من خصائص الطابعة، واستعمل خيار الطباعة اليدوي للطلبات ذات الوجهين.

## الاختبار

## ملاحظات أمنية
- لا يُحفظ أي ملف بعد الطباعة (مجلد مؤقت يُحذف).
- لا يُطبع إلا ما يعيده الخادم كملف PDF لمهمة أنشأها موظف مخوّل.
- كلمة المرور في `config.json` فقط؛ لا تُرسل إلا إلى العنوان المضبوط.
