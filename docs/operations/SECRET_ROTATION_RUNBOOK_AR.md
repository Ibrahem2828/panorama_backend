# دليل تدوير الأسرار

| السر | الأثر | الإجراء الآمن |
| --- | --- | --- |
| SECRET_KEY | يبطل جلسات Django الموقعة | جهز نافذة صيانة، غيّر في Coolify، أعد النشر، وتحقق من المصادقة. |
| FIELD_ENCRYPTION_KEY | قد يمنع فك الحقول القديمة | لا تدوّره بلا خطة re-encryption واختبار restore؛ احتفظ بخطة rollback مشفرة. |
| DB/Redis | قد يوقف التطبيق | أنشئ credential جديدًا، حدّث runtime env، نفذ health/smoke، ثم ألغ القديم. |
| SMTP/storage | يفشل الإرسال أو الوصول | جرّب على Staging بحساب محدود، بدّل runtime env ثم ألغ القديم. |
| JWT/Expo/Sentry | يبطل عملاء أو telemetry | دوّر مع فترة انتقال وراقب أخطاء auth/telemetry. |

لا تستخدم build args ولا تسجل القيمة القديمة أو الجديدة. سجل فقط اسم السر ووقت التدوير والمالك والنتيجة.
